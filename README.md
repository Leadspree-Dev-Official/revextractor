# Revenuecentra Extractor (RevExtractor)

Standalone extractor web app for configuring sources, launching scraping runs, and monitoring normalization, deduplication, and pipeline extraction jobs.

## Features
- Extractor interface for Google Business, Google Search, and connected directory connectors
- Pipeline preview & validation flow
- Live job tracking and record breakdowns (New, Duplicate, Invalid)
- Built with React, Vite, and Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
```
